- COO 사전검토 및 CTO QA 상담후속 재검토 문서는 **수정 전 df7f6c2 기준** 결함 기록이다. 최신 코드의 미해소 목록으로 그대로 읽지 않는다.

```powershell
node --test web/tests/*.test.mjs pipeline/tests/*.test.mjs
```

실서비스 데이터/DB와 테스트 mock의 검증 범위는 다르다. SQL 초안 실행과 실제 DB 연동 빌드의 미검증 여부는 구현 결과 문서를 따른다.
