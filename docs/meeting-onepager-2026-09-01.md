## 디스코드 공유용 본문

**[9/1 22:30 KOTA 팀 회의 원페이퍼]**

9/1 회의에서는 기술컨설팅 결과와 후속 작업을 공유하고, 각자 현재 상태·다음 산출물·기한을 확정합니다.

**1) 기술컨설팅 핵심**

- 화면 개편과 기존 동작 수정을 분리한다.
- 축제 고유 ID와 수집처 ID를 분리해 과거 주소·이용 기록을 보존한다.
- 한국 날짜·상태 규칙은 한곳에서 계산하고 테스트로 보호한다.
- 정적 생성은 유지하되 `allFestivals()`를 목적별 조회로 나눈다. 화면 파일 분리는 출시 전 필수가 아니다.

**2) 완료한 후속 작업**

- JIMFF 과거 주소 2개 복구, 한국시간 날짜 규칙 통합
- 테스트 10개·축제 누락 방지 정렬·ID 전용 조회 추가
- 데이터 증가로 빌드 응답이 잘리던 문제 해결
- 2,379페이지 빌드 및 운영 배포 완료, JIMFF·달력 운영 확인

**3) 남은 기술 작업**

1. 운영 DB와 끊어진 리뷰·로그를 읽기 전용으로 점검
2. 영속 ID·출처·과거 주소표와 백업/검증/롤백 준비
3. 기존 ID를 유지한 단계적 이전과 파이프라인 ID 재사용
4. 목록 요약 → 달력 기간 → 상세 1건 → 실시간 보정 조회 분리
5. 신규 축제 URL 테스트와 화면 역할 분리(핵심 안정화 이후)

**4) 팀원 진행 상황 — 시트 기록 기준, 본인 확인 필요**

- **전도준님:** 마케팅 엔진·마스터/CMO 문서·콘텐츠 OS·채널 목록·해외 고객조사·기관 자문 진행. 산출물, 막힘, 다음 공유일 확인.
- **최용우님:** 웹 QA·회의록·버그리포트 진행. 기능설명서 양식·이미지·흐름도 대기(시트 기한 9/6). 최신 QA와 기한 가능 여부 확인.

**5) 회의에서 결정할 것**

- DB 점검 담당·시작일과 영속 ID 검증자 1명
- 두 분의 다음 산출물·공유 날짜
- 공모전 마감 전 필수 범위와 이후로 미룰 범위
- 다음 중간 점검 시점
