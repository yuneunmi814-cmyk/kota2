### BUG-22 · 한국어 줄바꿈이 어절 중간에서 끊김 (P2 · 모바일)

```
저장소 kota2, 폴더 web/ 입니다.

문제: 모바일(375px) 홈 히어로에서 한국어 문장이 어절 중간에서 끊깁니다.
예: "지금, 어디로 가시" / "나요?"

원인: CSS에 word-break: keep-all 이 없습니다. 한국어는 영어와 달리 음절 단위로
끊으면 안 되고 어절(띄어쓰기) 단위로 끊어야 읽힙니다.

요청:
- app/globals.css 의 body 또는 공통 타이포 규칙에 word-break: keep-all 을 넣어 주세요.
- 다만 URL·이메일처럼 긴 문자열이 넘치면 안 되므로 overflow-wrap: anywhere 를 함께 둡니다.
- 영어·일본어·태국어 화면이 이상해지지 않는지 확인해 주세요. 태국어는 원래 띄어쓰기가
  거의 없으므로 keep-all이 문제를 일으키면 :lang(th) 로 예외를 두세요.

확인: npx next build 통과, 모바일 375px에서 홈 h1이 어절 단위로 끊기는지.
```
