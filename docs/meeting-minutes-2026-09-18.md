- 최용우가 기술컨설팅 후속 작업을 **브랜치로 올려 PR을 보냈으나, 윤은미가 아직 검토하지 못했다.**

- 윤은미: 회의 직후 최용우 PR을 확인하고, 컨설팅 작업 중 남은 것을 정리하기로 했다.
- 최용우의 AI 도구 사용량은 **9/19 오후에 다시 채워진다.**

## 2. 전도준 개선안 — 1단계부터, 하나씩

- 전도준이 개선안을 1단계·2단계로 나눠 정리해 올렸다. (녹취에 "6만 건"이라는 말이 나오나 무엇의 숫자인지는 미확인)
- **1단계만 먼저 하고 공유한다.** 항목 하나를 끝낼 때마다 확인한다(예: "끝난 축제 표시").
- 이유: 한 번에 다 넣으면 무엇이 어떻게 바뀌었는지 **윤은미도 최용우도 검수할 수 없다.**
- 최용우: 컨설팅에서 들은 대로 **기능을 한 곳에 몰지 말고 나눠서, 하나가 터져도 연달아 터지지 않게** 한다.

## 4. 지도 — 네이버로

- 전도준(카톡): 외국인은 카카오맵을 아예 쓰지 않는다. 앱을 새로 받아야 하는 허들이 크다. 구글로 바꾸자.
- 최용우: **구글 지도는 한국에서 길찾기 정보를 제대로 지원하지 않는다. 네이버는 된다.**
- **결정: 네이버 지도로 바꾼다.** 윤은미가 시도한다.
- 같이 나온 안: 구글·네이버 블로그 후기를 엮어 상세 페이지에 넣기(별도 폴더로 작업).

## 5. 포스터 문제

- 최용우가 안 뜨는 축제 하나를 직접 검색해 보니 **포스터는 실제로 존재했다**(다만 2025년도 것). 즉 "없어서"가 아니라 **못 불러오는 경우**가 있다.
- 추정 원인(전부 미확인): 관광공사 API 외에 엑셀로 받은 출처가 섞여 있음 / DB 갱신 누락 / 수집 중간 단계의 누락.
- **윤은미가 원인부터 파악한다.** 최용우 제안: DB를 한 번 갱신해 보고, 중간 과정을 AI로 점검해 본다.
- 끝내 못 고치면: **목록에서 빼지 않고 하단으로 내린다.** 상위 노출 조건은 이미지가 있는 것(전도준 카톡: 설정은 어드민에서).
  - 최용우의 지적: 제주처럼 **축제가 열몇 개뿐인 지역은 하위 노출이 의미가 없다.** 날짜순 필터를 걸면 어차피 섞인다.
- **포스터 없는 자리에 넣을 이미지**: 지금은 축제명 앞 글자를 따서 보여 준다 → **우리 로고로 통일한다.**
  - 최용우는 같은 그림이 반복되면 어색하니 열몇 장을 만들어 무작위로 넣자고 했고, 윤은미는 지저분해진다고 반대했다.
  - **결정: 로고(태극 문양)만 깔끔하게.**

## 6. 상세 페이지 — 템플릿 통일 (최용우)

- 축제마다 들어가는 정보 항목(메타데이터)을 고르게 맞춘 **템플릿**이 필요하다.
- 항목을 우리가 일일이 정할 시간이 없으니 **놀유니버스(구 인터파크)의 축제 정보 페이지 구성을 참고**한다.
- 담당 최용우. 윤은미는 자기 작업이 빨리 끝나면 알리고 먼저 손댈 수 있다.

## 7. 디자인 — AI 티, 로고, 시간대

- 최용우: 지금 디자인은 **AI가 만든 티가 많이 난다.** 하루 반나절이면 바꿀 수 있는데 아직 방향을 못 정했다.
- 윤은미: 처음엔 트립어드바이저를 그대로 따라 했는데 이제는 식상하다.
- 방향: **한국 느낌.** 흰 배경 대신 **한지 느낌**을 검토. 데이터를 먼저 손보면 디자인은 금방 입힐 수 있다. 최용우가 레퍼런스를 준다.
- **파비콘(브라우저 탭의 작은 아이콘)이 고깔 이모지로 바뀌어 있다** — 윤은미가 임의로 바꾼 것. **최용우가 만든 태극 문양 로고로 되돌린다.**
- **문양 디자인은 전도준이 맡는다**(회의 끝에 확인).
- 최용우가 챗GPT로 포스터풍 이미지 10장을 뽑아 공유 — 탈춤, 보름달과 정자, 야경 등. 반응이 좋았다.

- **구간을 어떻게 자를지(전도준 안 / 6시간 균등)는 이 회의에서 하나로 정리되지 않았다.** 담당은 최용우.
