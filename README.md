# KOTA 2 — 내 여행지 주변 축제 (전면 재구현)

2026-08-15 착수. 기존 `../kota`를 대체하는 새 구현이며, **기존 레포와 배포는
새 것이 확실히 나아질 때까지 그대로 살려둔다**(제출 기한 방어).

## 왜 다시 만드나

기존 화면은 '전국 축제 목록'의 얼굴이라 한국관광공사 구석구석(kfes)과 정면으로
겹쳤다. 예산·사진·에디토리얼로는 공사를 이길 수 없으므로, 겹치지 않는 자리로
옮긴다 — **여행자가 지금 있는 자리에서, 자기 언어로, 목적에 맞는 축제를 찾는 것.**

## 설계 기준

- UI/UX: 트립어드바이저 — 질문형 대형 헤드라인 + 큰 검색, 관심사 타일,
  큰 카드·큰 타이포·넉넉한 여백, 랭킹 섹션
- 기능: 구석구석(kfes) — 시기(개최중·예정·월별 12) × 지역 × 카테고리 3축 필터,
  축제달력, 인기 랭킹, 찜
- 우리만 있는 것: 다국어 축제명·요약(공사 영문 API는 축제 0건), 목적 테마
  자동분류, 위치 기반 '지금 여기', 앱 지오펜싱 알림

## 기존 구현에서 확인된 사실 (다시 발견하지 말 것)

- 공사 영문 API(EngService2)는 contentTypeId=15(축제)를 **0건** 반환한다
- TourAPI 쿼터 소진 시 **정상처럼 보이는 빈 응답**이 온다 — 센티넬 질의로 감지해야 한다
- kfes는 `cmsCntntsId` == TourAPI `contentid`. `locationx=null`(문자열)과 UA·Referer 필요
- 네이버 크롤러는 JS를 실행하지 않는다. GitHub Pages SPA 폴백은 HTTP 404를 준다
  → 빌드 시 실파일 생성이 유일한 해법
- 숫자 id는 환경마다 달라진다. 축제 식별은 반드시 `externalId`
